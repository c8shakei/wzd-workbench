# wzd 的工作台

一个**纯本地、零网络依赖**的个人工作台 Web App。数据全部存在浏览器 localStorage，不上传任何服务器。

## 功能模块

- **摸鱼区**：待办清单、政策速查、项目进度、CAD 字段工具
- **充电角**：今日一词 / 今日语法（六级词库，批量 10 条 + 换一批）、小测验、SM-2 间隔复习、连续打卡
- **离线查词**：内置 1033 词离线词库（CET6 + CET4 精选 + 办公词），毫秒级查询；未收录的词可一键加入个人词库自行补充

## 目录结构

```
index.html              页面结构
css/style.css           样式
js/dict_part1..5.js     离线词库分片（881 词，为降低单文件体积而拆分）
js/data.js              其余数据/配置（合并上述分片）
js/app.js               全部交互逻辑
.github/workflows/pages.yml   GitHub Actions 自动发布到 Pages
```

> 词库分片是为了便于分批上传，功能与单文件完全一致。

## 本地使用

直接用浏览器打开 `index.html` 即可，无需任何服务器或网络。

## 在线访问

通过 GitHub Pages 自动发布，推送到 `main` 分支后由 Actions 自动部署。
